# Rin - Engineering Guidelines

## Changes

- Keep changes focused on the requested task.
- Follow existing conventions before introducing new ones.
- Avoid unnecessary dependencies and abstractions.
- Preserve compatibility across Cargo feature configurations.
- Do not break existing public interfaces without justification.
- Preserve persistent user data during generation, cleanup, and lifecycle changes.

## Commits

- Write short, clear commit messages.
- Do not include `Generated by` in commit messages.
- Split unrelated changes into understandable commits.
- Manifest files may be modified but must not be committed by the agent.
- Notify the human about manifest changes requiring a commit

## Others

- Do not include `Generated by` in any message
